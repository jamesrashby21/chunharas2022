jsPsych v8 plugins

Visual working-memory and perception plugins for jsPsych v8: change detection, continuous report, forced choice, recognition, recall, similarity judgments, and more. They share one color wheel (which you can swap) and one set of helpers. Every trial records what was on screen, the response, its timing and how long the response was held.

Quick start

  1. Download the .zip and unzip it.
  2. Put your experiment's .html file in that folder.
  3. Load jsPsych v8 from a CDN, then the one file brady-plugins.bundle.js, and use the plugins in a normal jsPsych timeline. (Or load single files in the order brady-color-wheel.js → brady-plugin-utils.js → jspsych-*.js; the similarity plugins also need similarity-adaptive-utils.js before them.)
  4. Run it through a local web server, not by double-clicking: step-by-step for Windows and Mac.

The tutorial has the full page skeleton, an example for each plugin, saving and reading your data, and a troubleshooting table.

The plugins

  • change-detection — same/different memory (keyboard / buttons / radio; binary / confidence / two-stage; mask; noise)
  • 2afc-keyboard — perceptual forced choice over colors / images / words
  • continuous-report — delayed estimation of color and/or orientation; disks, lines, triangles, Gabors, or gratings
  • continuous-image-report — report on an image-morph wheel (sprite)
  • continuous-object-report / color-rotated-object — report the color of hue-rotated real-object photos (several at once, or one)
  • object-orientation-report — real objects studied rotated, then report orientation by spinning the probe
  • wm-forced-choice — working memory tested by picking the studied item from 2 or more options
  • wm-pairs — concentric two-color objects
  • noise-dots · recognition (old/new) · recall · spatial-report · rsvp
  • similarity-triad / similarity-quad / similarity-likert — similarity judgments, with fixed or adaptively chosen trials

The multi-item working-memory tasks can also show their items one at a time in their placeholders (sequential).
